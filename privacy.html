한국어

shorts-bridge(이하 "이 도구")는 유튜브 채널 에브리독 everydog(@everydogkr) 운영자가 본인 채널을 관리하기 위해 쓰는 개인용 도구입니다.

  • 사용하는 데이터: Google 계정 인증(OAuth)으로 받은 권한으로 운영자 본인 채널에 영상을 업로드·수정하고, 본인 채널의 YouTube 조회 통계(YouTube Analytics)를 읽습니다.
  • 보관: 인증 토큰과 게시 기록은 운영자 개인 컴퓨터에만 저장되며 외부 서버로 보내지 않습니다.
  • 제3자 제공: 어떤 데이터도 판매하거나 제3자와 공유하지 않습니다.
  • 다른 사용자: 이 도구는 운영자 외 다른 사람에게 제공되지 않으며, 다른 사람의 데이터를 수집하지 않습니다.
  • 권한 철회: Google 계정 권한 설정에서 언제든 접근 권한을 취소할 수 있습니다.

이 도구의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

English

shorts-bridge ("the tool") is a personal tool used by the operator of the YouTube channel everydog (@everydogkr) to manage that channel.

  • Data used: With permissions granted through Google OAuth, the tool uploads and edits videos on the operator's own channel and reads that channel's YouTube Analytics statistics.
  • Storage: Authorization tokens and publishing records are stored only on the operator's personal computer and are not sent to any external server.
  • Sharing: No data is sold or shared with third parties.
  • Other users: The tool is not offered to anyone other than the operator and collects no data about other people.
  • Revoking access: Access can be revoked at any time in Google Account permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy also apply.
